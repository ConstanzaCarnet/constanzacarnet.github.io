# Página de demos · Coti Carnet

Página a la que apunta el QR de la tarjeta. Reúne los ejemplos y el contacto por WhatsApp.

- Demo tienda / catálogo: https://constanzacarnet.github.io/demo-tienda-sumbu/
- Demo servicios / turnos: https://demo-studio-alma.vercel.app/

## Publicar (dirección corta, ideal para el QR)
1. En GitHub, crear un repo llamado exactamente **constanzacarnet.github.io**.
2. Subir esta carpeta (index.html y README.md).
3. Settings → Pages → Branch `main` / root → Save.
4. Queda en **https://constanzacarnet.github.io/** (las demos siguen funcionando en sus direcciones).

## Cambiar datos
- Número y mensaje de WhatsApp: al final de `index.html`, constantes `WHATSAPP` y `MENSAJE`.
- Para sumar una demo nueva: copiar un bloque `<article class="demo">` y cambiar textos y link.
